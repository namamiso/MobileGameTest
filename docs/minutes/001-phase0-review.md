# 議事録 001: フェーズ0完了レビューの指摘対応

- 日付: 2026-07-24
- 議題: フェーズ0(プロジェクトセットアップ)の完了レビュー指摘の採否

## 背景

計画のフェーズ完了レビューゲートに従い、新規サブエージェント2体
(A: 設定・コード品質観点 / B: 設計書との骨格突き合わせ観点)に並列レビューを実施。
計13件の指摘のうち、設計書・計画に影響するものが含まれたため議事録を作成する。

## 相談相手と意見の要旨

- **レビュアーA(設定品質)**: 空ディレクトリはgitで消失する、`next build --turbopack` は
  ベータでPixi導入後のリスク、`typecheck` スクリプト不足、vitest include が `.tsx` を拾わない、
  `.gitignore`/eslint ignores の小穴、`@types/node` のメジャー不一致
- **レビュアーB(骨格突き合わせ)**: 同じく空ディレクトリ問題、READMEがテンプレ残骸のまま
  (実装と矛盾する記述あり)、`ui/GameRoot.tsx` が TECH_DESIGN §3 に未記載、
  layout.tsx の viewport 設定(ズーム禁止)がどのドキュメントにも根拠なし、
  globals.css のテンプレ残骸

## 決定事項と理由

1. **全13件を採用**(対立する指摘なし)。主な対応:
   - 各ディレクトリに実ファイル名の型 placeholder を配置(`.gitkeep` 案は不採用 —
     計画の「型だけの placeholder」記述に合わせた)
   - `build` から `--turbopack` を外す(dev のみ維持)。Pixi 導入後の安定性を優先
   - `typecheck` スクリプトを追加し、計画のフェーズ完了コマンドにも追記
2. **viewport のズーム禁止は「外す」ではなく「設計書に追記して正当化」を選択**。
   放置ゲームは連打操作でズームが誤発動しやすく、ゲーム画面の固定が UX 上妥当と判断。
   TECH_DESIGN §11 に viewport 方針として明記した(採用しなかった案: 設定の削除)
3. **`ui/GameRoot.tsx` を TECH_DESIGN §3 に追記**(ドキュメントが常に正の原則)

## 影響

- TECH_DESIGN §3(GameRoot 追記)、§11(viewport 方針)
- IMPLEMENTATION_PLAN(フェーズ完了コマンドに typecheck)
- README.md を最小限の実態に合う内容へ書き換え
