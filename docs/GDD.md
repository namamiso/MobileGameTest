# ねこ茶屋 〜まったり放置経営〜 ゲームデザインドキュメント (GDD)

- バージョン: 0.1(テスト用初版)
- 対象プラットフォーム: モバイルブラウザ(縦持ち・片手操作)。デスクトップブラウザでも動作
- 技術スタック: Next.js + PixiJS(詳細は `TECH_DESIGN.md`)

## 1. コンセプト

江戸風の茶屋をねこたちが切り盛りする放置経営ゲーム。プレイヤーは茶屋の主人として、
ねこ店員を雇い、店を拡張し、放置している間も売上(小判)が貯まっていくのを眺めて癒される。

- ジャンル: 放置系クリッカー / インクリメンタルゲーム
- 1セッション想定: 30秒〜3分。1日に数回開いて回収・強化するプレイスタイル
- ターゲット: カジュアル層。数値インフレの気持ちよさ+ねこの可愛さで引っ張る

## 2. コアループ

```
タップで小判を稼ぐ
   ↓
ねこ店員を雇う(自動で小判を生産)
   ↓
売上で店員を増員・強化 → 生産量が指数的に増える
   ↓
成長が鈍化したら「のれん分け」(転生)で猫玉を獲得
   ↓
猫玉の永続ブーストで最初からより速く周回
```

## 3. 通貨

| 通貨 | 入手方法 | 用途 | リセット |
|------|---------|------|---------|
| 小判 | タップ / ねこ店員の自動生産 / オフライン収益 | 店員の雇用・増員 | のれん分けで0に戻る |
| 猫玉 | のれん分け(転生)時に累計売上に応じて獲得 | 永続の生産倍率(1個につき +2%) | リセットされない |

## 4. ねこ店員(ジェネレーター)

8種類。上位ほど基礎コスト・基礎生産が高い。購入するたびにコストが増加する。

| # | 名前 | 基礎コスト(小判) | 基礎生産(小判/秒) |
|---|------------|------------|------------|
| 1 | 子ねこ店員 | 15 | 0.1 |
| 2 | 茶運びねこ | 100 | 1 |
| 3 | 看板ねこ | 1,100 | 8 |
| 4 | 板前ねこ | 12,000 | 47 |
| 5 | 女将ねこ | 130,000 | 260 |
| 6 | からくり茶釜 | 1,400,000 | 1,400 |
| 7 | ねこ神社 | 20,000,000 | 7,800 |
| 8 | 招き猫像 | 330,000,000 | 44,000 |

### 数式

- n体目の購入コスト: `cost = baseCost × 1.15^owned`(Cookie Clicker 系の標準成長率)
- 種別の生産量: `production = baseProd × owned × milestoneMult × globalMult`
- マイルストーン倍率: 各店員の所持数が 25 / 50 / 100 / 200 体に達するごとに、その店員の生産 ×2
- グローバル倍率: `globalMult = (1 + 0.02 × 猫玉) × タップ強化などの倍率`

## 5. タップ

- 画面のねこ(店の中央)をタップすると小判を獲得
- タップ収入 = `max(1, 現在の総生産/秒 × 1%)` — 序盤の主収入、中盤以降は補助
- タップ時はねこが鳴く・小判が跳ねるなどのフィードバック(PixiJS 側で演出)

## 6. オフライン収益(放置の核)

- アプリを閉じている間も、最終保存時刻からの経過時間ぶん生産が進む
- 上限 **8時間**。超過分は切り捨て
- オフライン中の生産効率は **50%**(オンラインで眺めるインセンティブを残す)
- 復帰時に「おかえりなさい!○○小判 貯まりました」モーダルで一括受取

## 7. のれん分け(プレステージ)

- 解放条件: 累計獲得小判が 1,000,000 を超えると転生ボタンが出現
- 獲得猫玉: `floor(sqrt(累計獲得小判 / 1,000,000))` − すでに持っている猫玉換算分
- リセット対象: 小判・店員・マイルストーン。猫玉と統計は保持
- 猫玉1個 = 全生産 +2%(永続・加算)

## 8. 画面構成(1画面完結)

```
┌─────────────────────┐
│ 所持小判 / 毎秒生産量 (HUD)      │  ← React
├─────────────────────┤
│                     │
│   茶屋のシーン(PixiJS Canvas)   │  ← タップ領域
│   雇った店員のねこが表示される       │
│                     │
├─────────────────────┤
│ [店員] [強化] [のれん分け] タブ    │  ← React
│  店員リスト(購入ボタン付き)       │
└─────────────────────┘
```

- 店員を雇うとキャンバス内のねこが実際に増える(種別ごとに最大表示数あり、超過分は「×N」バッジ)
- 数値表記: 1万以上は日本語単位(万・億・兆・京 …)で丸め表示

## 9. セーブ

- 自動保存: 10秒ごと+タブ非表示時(visibilitychange)
- 保存先: localStorage(テスト版)。スキーマにバージョン番号を持たせマイグレーション可能にする
- 手動リセット(全削除)を設定メニューに用意
