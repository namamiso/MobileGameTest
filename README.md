# ねこ茶屋 〜まったり放置経営〜

ねこたちが切り盛りする茶屋の放置経営ゲーム(テストプロジェクト)。
Next.js 15 + PixiJS v8 + zustand + break_infinity.js。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # game-core の単体テスト (vitest)
npm run typecheck  # tsc --noEmit
npm run build      # 本番ビルド
```
